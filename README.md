# DevOps Lab

My hands-on journey from fullstack developer to DevOps.

## Stage 1: Linux Server Bootstrap

A Bash script that turns a fresh Ubuntu server in a secured server in one command.

### What it does
- Updates all packages
- Hardens SSH (key-only login, no root login)
- Enable firewall (ufw)
- install tools

### Usage

```bash
./scripts/bootstrap.sh
```
